One funny single-line one-star review from a house cat about its human, entered in the [make.fun bounty](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

## The entry

> One star. He bought a $60 cat bed, then acted betrayed when I slept in the box it came in. The box stays. He can go.

## Why this line

Every cat owner recognises the joke instantly: the expensive bed is ignored, the cardboard box is the true throne. The complaint stays deadpan — a real one-star review shape — while the sting lands in the last three words, where the cat calmly evicts the human instead of the other way round. The review gives away more about the cat than the owner: by cat standards, the human failed the only test that matters, and the box is non-negotiable.

The line is a single line well inside the bounty gate of 1–200 characters, so it passes the sealed scorer's validity check before it ever meets the judge.

## How it works

`main.ts` (Node 22, no dependencies) writes the line to `/output/entry.txt`, falling back to `./output/entry.txt` when run locally, and refuses to write a blank line or one over the 200-character limit.

```sh
node main.ts
```
